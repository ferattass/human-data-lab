# Davranış kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) davranış kurallarını benimser.
Kuralların tam metni o bağlantıdadır ve bu projenin tüm alanlarında (issue, pull request, tartışma) geçerlidir.

Kısaca: herkese saygılı olun; kişi, köken, dil veya yazı sistemi üzerinden aşağılayıcı dil kullanmayın.
Bu proje insan adlarının ve yazı sistemlerinin çeşitliliğini konu alıyor: fixture tartışmalarında
ülke stereotipi yerine sınanan **metin davranışından** söz edin.

## Bildirim

Kural ihlallerini proje bakımcılarına GitHub üzerinden özel olarak bildirin
(repo sahibine doğrudan mesaj veya **Security → Report a vulnerability** formu, konu satırında "Code of Conduct").
Bildirimler gizli tutulur.
