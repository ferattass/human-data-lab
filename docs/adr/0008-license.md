# 0008 — Apache-2.0

**Karar.** Özgün çekirdek kodu, CLI, reporter ve özgün sentetik fixture'lar Apache License 2.0 ile lisanslanır (rapor §42).
Üçüncü taraf corpus içeriği otomatik yeniden lisanslanmaz; köken ve lisans fixture başına kaydedilir. Şu an üçüncü taraf içerik yoktur.

**Not.** Hukuki inceleme sonucu değildir; dağıtımdan önce bağımlılık lisansları kontrol edilir.
